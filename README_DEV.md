# Aria ERP - Developer Setup Guide

Welcome to **Aria ERP**, a pharmacy and business management system designed with a modern full-stack architecture using React, Express, and MySQL.

---

# Project Overview

Aria ERP is built to manage:
- Product inventory
- Sales and transactions
- Employee records
- Reporting and analytics
- Pharmacy operations

The application uses:
- **Frontend:** React 19 + Vite + Tailwind CSS
- **Backend:** Express.js API server
- **Database:** MySQL/MariaDB
- **Architecture:** Hybrid SQL + Firebase transition structure
